## Module 1: 平台經濟與網絡效應（Platform Economy & Network Effects）

### 1.1 平台經濟的本質

- 平台不是傳統的「生產者」，而是**「市場的組織者」（Market Organizer）**。
- 核心價值來源：**連接（Connection） + 網絡效應（Network Effects） + 數據反饋迴路（Data Feedback Loop）**。
- 與傳統管道經濟（Pipeline Economy）的最大分別：平台不擁有資產，而是透過匹配供需雙方創造價值。

### 1.2 網絡效應的兩種類型

**直接網絡效應（Direct Network Effects）：** 同一邊用戶越多，價值越高。
- 例子：微信、WhatsApp、電話、社群媒體

**間接網絡效應（Indirect Network Effects）：** 兩邊用戶互相依賴。
- 例子：Uber（司機越多 → 乘客越多 → 司機又更多）、Airbnb、支付平台、電商平台

### 1.3 雙邊市場的「雞蛋問題」（Chicken-Egg Problem）

- 平台需要同時吸引買家和賣家，但如果一方用戶不足，另一方也不願加入。
- 解決方法：通常先補貼其中一方（例如乘客、內容消費者），快速建立網絡效應，再向另一方收費。

### 1.4 平台定價策略

**常見策略：** 對需求彈性高或價值較低的一方補貼，對另一方（尤其是高價值用戶或商家）收取較高費用。

**常見 monetization 方式：**
- 交易佣金（Transaction Fee）
- 訂閱費（Subscription）
- 廣告收入（Advertising）
- 增值服務 / Premium 功能

## Module 2: 數據經濟與價值化（Data Economy & Monetization）

### 2.1 數據的三個價值層次

| Level | 描述 | 例子 |
|-------|------|------|
| **Level 1** | 數據作為營運成本 | 儲存、安全、合規 |
| **Level 2** | 數據作為決策工具 | 分析、推薦系統、預測 |
| **Level 3** | 數據作為可交易資產 | Data Marketplace、模型訓練數據、廣告 targeted、數據授權 |

### 2.2 數據價值化的商業模式

- **Targeted Advertising**（精準廣告）
- **Personalization & Recommendation**（個人化推薦）
- **Data Licensing / Selling**（數據授權）
- **AI Model Training Data**（AI 訓練數據）
- **Data-driven Product / Service Improvement**（數據驅動改進）

### 2.3 香港在數據價值化方面的挑戰

- 《個人資料（私隱）條例》（PDPO）規管嚴格
- 數據跨境流動限制
- 數據孤島嚴重（政府 vs 私營機構）
- 數據科學及 AI 人才相對短缺
- 公眾對私隱的敏感度高

## Module 3: 數字轉型與 AI 經濟學（Digital Transformation & AI Economics）

### 3.1 AI 對經濟的影響

- **生產力提升：** 自動化、重複性工作被取代
- **就業結構改變：** 低技能 routine work 減少，高技能 + AI 輔助工作增加
- **市場結構變化：** Winner-takes-most 效應更強（數據 + 網絡效應雙重優勢）

### 3.2 數字轉型對企業的影響

- 從「產品導向」轉向「平台 + 數據 + 生態」導向
- 傳統企業若未能完成數字轉型，容易被平台型企業顛覆

### 3.3 香港的數字轉型現況

- 政府推動「數字經濟藍圖」及「Web3 政策」
- 挑戰：人才流失、監管確定性不足、與內地數據連接的限制

## Module 4: 數字市場的反壟斷與監管（Antitrust & Regulation in Digital Markets）

### 4.1 平台壟斷的現代特徵

| 傳統壟斷 | 平台壟斷 |
|----------|----------|
| 高價格 | 零價格 |
| 低產量 | 數據壟斷 |
|  | 自我優待（Self-preferencing）|
|  | 排除競爭 |

**常見問題：** App Store 抽成、搜索結果偏袒自家服務、數據不公平使用

### 4.2 香港《競爭條例》重點

- 禁止具有「相當程度的市場權勢」（Substantial Market Power）的企業濫用權勢
- 重點關注：排除競爭、歧視性定價、拒絕提供必要設施、自我優待
- 競爭事務委員會（Competition Commission）有權調查及罰款

### 4.3 中國反壟斷經驗對香港的啟示

- 阿里巴巴、騰訊、美團等案例顯示，即使是平台經濟也不能無限制擴張
- 香港應加強對大型科技平台的監管，尤其在數據壟斷和對中小商家的不公平條款方面
- 避免出現「贏家通吃」局面，保護市場競爭與創新

## Module 5: Web3、加密資產與 Token 經濟（Web3, Crypto Assets & Tokenomics）

### 5.1 Tokenomics 核心概念

- Token 不只是「幣」，而是**權利、激勵、治理的載體**
- 常見 Token 類型：
  - **Utility Token**（功能型）
  - **Security Token**（證券型）
  - **Governance Token**（治理型）
  - **Payment Token**（支付型）

### 5.2 香港 Web3 監管框架

- **SFC 虛擬資產交易平台牌照（VASP）**
- **穩定幣監管框架**（2024–2025 逐步推出）
- **HKMA 對 CBDC（e-HKD）的研究**
- 「一國兩制」下，香港可成為連接內地與全球 Web3 的橋樑

### 5.3 Token 經濟的風險與機遇

**機遇：**
- 新型融資
- 社區治理
- 資產 tokenization
- 去中心化金融（DeFi）

**風險：**
- 波動性
- 監管不確定性
- 詐騙
- 洗錢

## Module 6: 數字貿易與全球化（Digital Trade & Globalization） + 香港視角

### 6.1 數字貿易的新特徵

- 數據跨境流動成為關鍵生產要素
- 服務貿易（尤其是數字服務）比重上升
- 傳統比較優勢理論需要更新（從勞動/資本轉向「制度 + 數據 + 生態」）

### 6.2 香港的定位與策略

**優勢：**
- 普通法體系
- 國際金融中心
- 與內地緊密連接
- 「一國兩制」

**挑戰：**
- 人才流失
- 數據跨境限制
- 與新加坡/迪拜的競爭

**建議策略：**
- 深化 CEPA 數字貿易專章
- 積極參與 RCEP、CPTPP 等區域數字貿易協議
- 打造「內地數據 + 香港規則 + 國際資本」的跨境數據及 Web3 樞紐
