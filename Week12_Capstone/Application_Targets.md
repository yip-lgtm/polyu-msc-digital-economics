## 3. 面試準備 Checklist

### 3.1 技術準備

- [ ] 熟悉 OpenClaw AI Trading Agent 嘅每個 component
- [ ] 背熟 ICT Smart Money Concepts（FVG、OB、Liquidity Sweep）
- [ ] 解釋 Sharpe 2.31 嘅計算方式
- [ ] 解釋 OLS 迴歸 HC3 標準誤
- [ ] 知道 HK VASP 牌照流程
- [ ] 了解 SFC 對 AI 嘅最新指引
- [ ] 比較 HashKey、OSL 嘅分別

### 3.2 行為面試（Behavioral）

- [ ] **Why HK Web3?** — 個人故事 + 政策時機
- [ ] **Why [Company]?** — 公司具體戰略 + 自己匹配點
- [ ] **Biggest challenge?** — Yahoo Finance rate limit / Sandbox IP
- [ ] **Failure example?** — Yahoo rate limit / 投遞失敗
- [ ] **5-year goal?** — 從 AI Trading 到 Web3 Startup
- [ ] **AI Ethics view?** — Octopus / Foodpanda 案例

### 3.3 案例分析題

- [ ] **設計 AI Trading Agent 給香港散戶** — 合規 + 風險
- [ ] **OpenClaw 點解選擇 ICT** — 解釋點解 ICT 適合 OpenClaw
- [ ] **香港 VASP vs 新加坡** — 監管競爭
- [ ] **穩定幣監管框架** — 2025 新例

1. "請問貴公司對 AI 交易嘅長遠策略係點？"
