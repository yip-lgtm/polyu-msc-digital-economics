# OpenClaw AI Trading Agent — ICT Smart Money Concepts

This project integrates **Inner Circle Trader (ICT) Smart Money Concepts** with the **OpenClaw AI agent framework** to enable autonomous, rule-based trading in cryptocurrency and futures markets. It serves as a practical demonstration of combining institutional trading logic with modern AI agent architecture, developed as part of a 12-week self-study programme equivalent to **PolyU's MSc in Digital Economics**.

## 🎯 Project Overview

The agent is designed to consume structured trading signals generated by the **Python ICT Dashboard V2** and autonomously evaluate and execute trades based on ICT methodology. It demonstrates how traditional institutional trading concepts can be operationalised in a modern, auditable, and regulator-friendly way.

**Live deployment:** Paper trading on HashKey (since March 2025)
**Target markets:** BTC-USD, ETH-USD, SOL-USD + MES=F (Micro E-mini Nasdaq futures)

## 🏗️ Architecture (3-Module)

```
┌─────────────────────────────────────────────────────────┐
│  PERCEPTION MODULE                                       │
│  - Python ICT Dashboard V2 (FVG, OB, Liquidity Sweep)   │
│  - Real-time market data ingestion                       │
│  - JSON signal output                                    │
└────────────────────┬────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────┐
│  REASONING MODULE                                        │
│  - Rule-based ICT validation                             │
│  - Risk-reward evaluation                                │
│  - HTF context filter                                    │
│  - Position sizing (Kelly Criterion)                     │
└────────────────────┬────────────────────────────────────┘
                     ↓
┌─────────────────────────────────────────────────────────┐
│  ACTION MODULE                                           │
│  - Order execution (paper trading)                       │
│  - Stop-loss / take-profit management                    │
│  - Trade logging + audit trail                           │
│  - Performance monitoring (Prometheus)                   │
└─────────────────────────────────────────────────────────┘
```

The modular design allows **independent testing, debugging, and regulatory auditing** of each component — a critical requirement for Hong Kong's VASP framework.

## ✨ Key Features

### 1. ICT Smart Money Concepts
- **Order Block (OB) detection** — institutional entry/exit zones
- **Fair Value Gap (FVG) detection** — price imbalance zones
- **Liquidity Sweep detection** — stop hunt patterns
- **Higher-timeframe context** — discount/premium array

### 2. Modular Architecture
- **Perception** ingests and structures data
- **Reasoning** applies ICT rules + risk management
- **Action** executes trades with full audit trail

### 3. Compliance-Ready
- **Audit trail:** Every decision logged with reasoning
- **Explainability:** LIME/SHAP for trade rationale
- **PDPO compliant:** No PII collected
- **SFC VASP ready:** Modular design supports regulator inspection

### 4. Risk Management
- **Position sizing:** Fractional Kelly (1/4 Kelly)
- **Drawdown protection:** Auto-pause at 8% drawdown
- **Daily/weekly/monthly loss limits:** 2%/5%/10%
- **ATR-based stop loss:** 1.5x ATR

## 🔗 Integration with Python ICT Dashboard V2

The OpenClaw agent **consumes JSON signals** generated by the Python ICT Dashboard V2 (separate process):

1. **ICT Dashboard V2** runs continuously, detecting OB/FVG/Liquidity Sweep patterns
2. **JSON output** written to `signals_json/` directory
3. **OpenClaw Reasoning Module** picks up new signals, evaluates against rules
4. **Action Module** executes paper trades based on validated signals
5. **Execution logs** written to `execution_logs/`

This decoupling ensures the heavy-lifting signal detection can run independently from the trading agent logic.
