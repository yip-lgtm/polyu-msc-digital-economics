## 核心概念

**1. Macroeconomics 研究什麼？**

研究整個經濟體嘅行為，包括 GDP、失業、通脹、貨幣政策、財政政策等。

**2. GDP 的三種計算方法：**

1. **生產法（Production Approach）** — 計算所有生產嘅最終產品價值
2. **支出法（Expenditure Approach）** — C + I + G + (X - M)
3. **收入法（Income Approach）** — 工资 + 租金 + 利息 + 利潤

**3. Aggregate Demand (AD) Curve 為什麼向下傾斜？（至少寫 3 個原因）**

- **Wealth Effect（P↓ → Real Wealth↑ → C↑）**
- **Interest Rate Effect（P↓ → i↓ → I↑ + C↑）**
- **Net Export Effect（P↓ → M↑ + X↑ → NX↑）**

**4. Short-run Aggregate Supply (SRAS) 與 Long-run Aggregate Supply (LRAS) 的分別：**

- **SRAS：** 短期內工資/物價僵硬，向上傾斜
- **LRAS：** 長期內工資/物價靈活，垂直於充分就業產出水平

**5. 令 AD Curve 右移的 4 大原因：**

1. **C（消費）↑** — 消費信心增強、財富效應
2. **I（投資）↑** — 利率下降、預期回報上升
3. **G（政府支出）↑** — 財政刺激
4. **NX（淨出口）↑** — 出口↑、進口↓

**6. 令 SRAS Curve 右移的 3 大原因：**

1. **生產成本↓**（工資、油價、原材料）
2. **技術進步** — 生產力提升
3. **預期通脹↓** — 工資/價格設定更穩定

## AD-AS 圖 5 大情境（參考答案）

### 1. AD 右移 → 短期均衡（P*↑ Y*↑）
```
P  |        SRAS
   |       /
   |   P2•/---- AD₂
   |     / •
   | P1•/----- AD₁
   |   / •
   |  / Y₁  Y₂
   +---------------- Y
   AD 右移令 Y* 上升，P* 上升（通脹壓力）
```

### 2. AD 左移 → 短期均衡（P*↓ Y*↓）
```
P  |   SRAS
   |  /
   | •---- AD₁
   |P₂•
   | •---- AD₂
   |P₁• Y₂ Y₁
   +---------------- Y
   AD 左移令 Y* 下降，P* 下降（衰退）
```

### 3. SRAS 右移 → 長期調整
```
P  |   SRAS₂  SRAS₁
   |  /     /
   | •-----•----- AD
   |P₁•    •P₂
   |  \    \
   |   LRAS
   +---------------- Y
   SRAS 右移令 P* 下降（通縮），Y* 不變（長期）
```

### 4. SRAS 左移（成本上升，例如油價上升）
```
P  |     SRAS₁  SRAS₂
   |    /      /
   |  P₂•-----•----- AD
   |    •     /P₁
   |  P₃•    /
   |    LRAS
   +---------------- Y
   Stagflation: P* 上升，Y* 下降
```

### 5. 長期均衡回到 LRAS（自我修正機制）
```
P  |      SRAS₂ SRAS₁
   |     /     /
   |   /   •--/-- AD
   |  /  / •P₂
   |  / / P₁
   |  LRAS
   +---------------- Y
   長期內 SRAS 右移返，P* 回到原位，Y* 不變
```
