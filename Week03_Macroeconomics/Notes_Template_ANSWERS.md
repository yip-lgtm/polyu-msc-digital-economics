## 核心概念

**1. Macroeconomics 研究什麼？**

研究整體經濟（aggregate economy），包括 GDP、失業率、通脹、經濟增長、商業周期、財政與貨幣政策等。

**2. GDP 的三種計算方法：**

1. **支出法（Expenditure Approach）** — C + I + G + (X - M)
2. **收入法（Income Approach）** — 工资 + 租金 + 利息 + 利潤
3. **生產法 / 增值法（Production / Value Added Approach）** — 所有最終產品嘅價值

**3. Aggregate Demand (AD) Curve 為什麼向下傾斜？（至少寫 3 個原因）**

1. **財富效應（Wealth Effect）：** 物價上升 → 實質財富減少 → 消費減少
2. **利率效應（Interest Rate Effect）：** 物價上升 → 貨幣需求增加 → 利率上升 → 投資減少
3. **匯率效應 / 淨出口效應（Exchange Rate / Net Export Effect）：** 物價上升 → 本國貨幣實質升值 → 出口減少、進口增加 → 淨出口減少

**4. Short-run Aggregate Supply (SRAS) 與 Long-run Aggregate Supply (LRAS) 的分別：**

- **SRAS：** 向上傾斜（Upward sloping）。因為短期內工資與價格具有黏性（sticky wages & prices），物價上升時，企業利潤增加，願意增加生產。
- **LRAS：** 垂直（Vertical）。長期內經濟處於潛在產出（Potential Output）水平，資源已充分利用，物價變化不會影響實際產出。

**5. 令 AD Curve 右移的 4 大原因：**

1. 消費增加（C↑）
2. 投資增加（I↑）
3. 政府開支增加（G↑）
4. 淨出口增加（NX↑）（例如外國收入上升或本國貨幣貶值）

**6. 令 SRAS Curve 右移的 3 大原因：**

1. 投入品價格下降（例如油價下跌、工資下降）
2. 生產力上升（技術進步）
3. 預期物價下降（企業願意以較低價格供應）

## AD-AS 圖手寫練習 — 答案說明（請按以下描述手畫）

### 圖 1: AD 右移 → 短期均衡（P*↑ Y*↑）
- AD 曲線向右移動
- 新均衡點：價格上升（P*↑）、產出上升（Y*↑）
- SRAS 不動 → 短期內出現通脹缺口（Inflationary Gap）

### 圖 2: AD 左移 → 短期均衡（P*↓ Y*↓）
- AD 曲線向左移動
- 新均衡點：價格下降（P*↓）、產出下降（Y*↓）
- SRAS 不動 → 短期內出現衰退缺口（Recessionary Gap）

### 圖 3: SRAS 右移 → 長期調整
- SRAS 向右移動（例如生產力上升）
- 短期：P*↓、Y*↑
- 長期：經濟自我修正，AD 不變，最終回到 LRAS（Y* 回落至潛在產出）

### 圖 4: SRAS 左移（成本上升，例如油價上升）
- SRAS 向左移動
- 新均衡點：P*↑、Y*↓（滯脹 Stagflation 特徵）
- 短期內物價上升但產出下降

### 圖 5: 長期均衡回到 LRAS（自我修正機制）
- 假設出現衰退缺口（AD 左移）
- 短期：失業率上升 → 工資下降 → SRAS 逐漸右移
- 最終回到 LRAS（Y* 回升至潛在產出，P* 進一步下降）

## 🎯 4 條分析題參考答案

1. **香港經濟目前處於 AD-AS 模型的哪個區域？**
   - **接近長期均衡至溫和增長區域**。2026 Q1 GDP +5.9% 顯示 AD 強勁右移（出口 + 內需），但 SRAS 較陡峭（勞工短缺）令通脹可控。

2. **2026年通脹壓力主要來自哪一方（AD 還是 AS）？**
   - **主要來自 AD 端**。AD 右移帶來需求拉動型通脹，但 SRAS 較陡峭限制了通脹幅度。

3. **如果美國減息，會如何影響香港的 AD 曲線？**
   - **AD 右移**。美國減息 → 港美息差收窄 → 資金流入香港 → 資產價格上升 → 財富效應 → 消費增加。同時企業借貸成本下降 → 投資增加。

4. **對香港2026全年增長 2.5–3.5% 的預測，你是否同意？為什麼？**
   - **同意，但可能有上行風險**。理由：(a) 出口 + AI 需求強勁 (b) 內需復蘇 (c) 旅遊業持續回升。但下行風險包括：地緣政治、貿易摩擦、樓市調整。
