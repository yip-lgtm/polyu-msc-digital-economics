# 📋 Week Completion Templates

> **Standardized templates for documenting week-by-week progress in the 12-week PolyU MSc Digital Economics self-study programme.**

---

## Available Templates

| Template | Style | Use Case |
|----------|-------|----------|
| [`_template_completion.md`](./_template_completion.md) | **Comprehensive** (10 sections) | Detailed retro, portfolio showcase, professional documentation |
| Existing `Week0X_*/completion.md` (11 files) | **Simple checklist** | Quick tracking during the week |

---

## Two-Tier Approach

### Tier 1: Simple Checklist (existing 11 weeks)
- Lightweight, in-week tracking
- 4-5 sections: Date, Subject, Tasks, Case Studies, Next
- Format: `[ ]` checkboxes + bullet points
- File location: inside each `Week0X_*/` folder
- Best for: momentum tracking while studying

### Tier 2: Comprehensive (new template)
- 10 sections including: Learning Objectives, Achieved Outcomes, Key Deliverables, Concepts Mastered, Lessons Learned, Connections, Time Investment, Tools, Notes
- Format: tables + structured headings
- File location: root of repo (`_template_completion.md`)
- Best for: end-of-week retros, portfolio artefacts, HR/employer review

---

## Recommendation

**Use Tier 1 (simple) during the week** for real-time tracking.
**Upgrade to Tier 2 (comprehensive) at week end** if creating portfolio piece.

For the current 12-week programme (completed 2026-06-06), the 11 existing Tier 1 files are sufficient evidence of completion. The Tier 2 template is provided as a **future upgrade path** for any user who wants richer documentation.

---

## Quick Copy-Paste

To use Tier 2 in a new week:

```bash
cp _template_completion.md Week13_NewTopic/completion.md
# Then fill in the [brackets] and add specifics
```
